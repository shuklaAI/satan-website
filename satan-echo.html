How to Start SATAN

STEP 01 — CLONE REPOSITORY

git clone https://github.com/shuklaAI/SATAN.git

STEP 02 — ENTER DIRECTORY

cd SATAN

STEP 03 — VIRTUAL ENVIRONMENT

python -m venv .venv .\.venv\Scripts\Activate.ps1

STEP 04 — INSTALL DEPENDENCIES

pip install -r requirements.txt playwright install

STEP 05 — CONFIGURE API KEYS

Create config/api_keys.json:

{ "gemini_api_key": "YOUR_GEMINI_API_KEY", "openrouter_api_key": "YOUR_OPENROUTER_API_KEY" }

Gemini is the primary AI provider.
OpenRouter is optional but recommended as fallback support.

STEP 06 — START SATAN

python main.py

Or use the easier Windows startup option:

start_SATAN.vbs
