# SATAN Echo

A cinematic landing page and product showcase for SATAN Echo, an AI desktop assistant designed to see, think, and act across your computer.

## Overview

SATAN Echo is positioned as a personal desktop intelligence layer for Windows users. The experience combines:

- Voice-first interaction
- Text-based command control
- PC automation and workflow assistance
- Screen-aware intelligence
- AI-powered content creation and task execution
- Mobile companion connectivity via SATAN Connect

The site is built as a single-page dark, red-lit experience with animated backgrounds, a vertical navigation rail, and sections covering the product, login flow, downloads, mobile support, setup steps, and feedback.

## Files

- `satan-echo.html` — the full landing page and interactive website
- `README.md` — project overview and local preview instructions

## Local Preview

To view the site locally:

1. Open the project folder in your browser.
2. Open `satan-echo.html` directly, or
3. Serve it locally with a simple web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/satan-echo.html
```
